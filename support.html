Getting started

You need an iPhone or iPad with iOS 17 or later, and an openmediavault 7 or 8 server you can reach from it.

  1. Open OMV Remote and tap Add Server.
  2. Enter the address you use for the openmediavault web interface (for example https://nas.local or 192.168.1.20), your username and password.
  3. Tap Test connection, then save. Allow local network access when iOS asks.

Want to look around first? Tap Try Demo NAS on the dashboard. Leave it under More › Exit demo.

Can't connect

  • Make sure your device is on the same Wi-Fi as the server, or connected to your VPN.
  • Allow local network access: Settings › Privacy & Security › Local Network › OMV Remote.
  • Check the address, the port and whether the server uses HTTPS or HTTP — open the same address in Safari to compare.
  • If the password is right but sign-in fails, check the account isn't disabled in openmediavault.

Certificate prompts

If your server uses a self-signed certificate, the app shows its SHA-256 fingerprint the first time you connect. Compare it with the fingerprint shown on the server before tapping Trust. If the app later says the certificate changed and you didn't renew it, don't accept the change — something may be intercepting the connection.

Two-factor sign-in

If your openmediavault account uses an authenticator app, OMV Remote asks for the six-digit code after your password. Codes change every 30 seconds, so enter the current one.

“Admin only” and missing figures

openmediavault gives CPU, memory, uptime, load, network traffic and disk-health information only to administrator accounts. With a read-only account these show Admin only. Monitoring still works for everything else; sign in as an administrator to see the rest and to make changes.

  • Network shows “Measuring…” — throughput is calculated from two readings, so it appears after the next refresh.
  • CPU temperature is unavailable — it needs the openmediavault CPU Temperature plugin with a working sensor.
  • A volume shows “—” — openmediavault couldn't read that filesystem's usage, for example a disconnected USB drive.

Disk health (S.M.A.R.T.)

Storage shows openmediavault's own verdict for each disk. Tap SMART details for temperature, power-on hours and the attribute table. NVMe and SAS drives don't report an attribute table. Self-tests run as scheduled jobs in the openmediavault web interface (Storage › S.M.A.R.T. › Scheduled tasks).

Docker

Docker features need the openmediavault Compose plugin (openmediavault-compose, from omv-extras). Starting, stopping or restarting a container always asks for confirmation and Face ID.

Alerts and notifications

Turn on Settings › Alert notifications to be told when storage runs low, a disk reports problems or gets hot, or a server can't be reached. Thresholds and quiet hours can be set for each server. If you previously declined notifications, allow them in Settings › Notifications › OMV Remote.

iOS decides when apps refresh in the background, so alerts can be delayed while the app is closed. For round-the-clock alerts, run the optional Companion on your server — see the project's README.

Widgets

Touch and hold the Home Screen, tap Edit › Add Widget and choose OMV Remote. Widgets show the readings from the app's last refresh and dim when they're old; open the app or tap the refresh button to update them. To keep server details off your Home Screen, turn off Settings › Show server status in widgets.

Wake NAS

Enter the server's MAC address under More › Wake NAS. Wake-on-LAN must be enabled in the server's firmware (BIOS/UEFI) and network settings. The packet stays on your local network, so it won't usually cross routers, VLANs or VPNs.

Face ID and app lock

The app unlocks with Face ID, Touch ID or your device passcode, which also protect your saved passwords. Without a device passcode, iOS can't store protected passwords, so set one to add servers. Change how quickly the app locks under Settings › Lock after inactivity.

Removing your data

Remove a server in the app to delete everything stored for it, including its password and history. Deleting the app removes all its data. See the Privacy Policy for details.

Reporting a problem

Email us with the steps that lead to the problem. A diagnostic summary helps: open More › Diagnostics & Crash Logs, tap Prepare summary JSON, then Share diagnostics summary. It contains app and device diagnostics, never passwords or server credentials — check it before sending. Please report security issues privately by email rather than in public.
